EMULATION · WINDOWS CE

CERF — CE Runtime Foundation

An open-source Windows CE emulator project that can run classic Windows CE environments and supported device configurations. CERF itself runs on supported desktop platforms; it is not an app to install directly on a Pocket PC.

Latest listed release: 8.0 (build 659) · Windows 32-bit, Linux, macOS Apple silicon, and Android ARM64 packages are listed by the project.

License: CE Runtime Foundation License 1.1 (non-commercial terms apply); third-party components have their own notices.

Official downloads ↗GitHub releases ›Source & project details ›

CERF describes itself as a beta hobby project; expect bugs or crashes. Read the current release notes and license before installing or redistributing.

Before installing old software

  • Confirm the exact device model and Windows Mobile or Pocket PC version.
  • Check who provided the file and whether the original publisher is known.
  • Scan files with up-to-date security software; don't disable protections to run an unknown installer.
  • Back up your device before installing or changing system software.
